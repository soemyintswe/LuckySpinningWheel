# Lucky Wheel အသုံးပြုပုံလမ်းညွှန်

ဤလမ်းညွှန်သည် ကံစမ်းသူ/အလှူရှင်များနှင့် Admin တို့အတွက် ဖြစ်ပါသည်။ App ကို [luckydraw-mksdev.web.app](https://luckydraw-mksdev.web.app) မှဖွင့်ပြီး browser ဟောင်း cache မဖြစ်စေရန် လိုအပ်သည့်အခါ `Ctrl + Shift + R` ဖြင့် ပြန်ဖွင့်ပါ။

## ၁။ ကံစမ်းသူနှင့် အလှူရှင် အသုံးပြုပုံ

### အကောင့်ဖွင့်ခြင်းနှင့် ဝင်ခြင်း

1. **အသင်းဝင်စာရင်းသွင်းရန်** ကိုနှိပ်ပြီး အမည်၊ ဖုန်း၊ Email နှင့် စကားဝှက်ဖြည့်ပါ။ Google ဖြင့်ဝင်ခြင်းလည်းရပါသည်။ Facebook ကို Firebase Authentication တွင် Admin က ဖွင့်ထားမှ အသုံးပြုနိုင်ပါသည်။
2. Viber နှင့် Telegram အချက်အလက်သည် ဆက်သွယ်ရန်အတွက်သာဖြစ်ပြီး အဲဒီအကောင့်များဖြင့် တိုက်ရိုက်ဝင်ခြင်း မဟုတ်ပါ။
3. အကောင့်ကို တစ်ကြိမ်သာဖွင့်ပါ။ Admin အတည်ပြုပြီးမှ မဲအစီအစဉ်များတွင် ဝင်နိုင်ပါမည်။ အကောင့်အတည်ပြုခြင်းသည် မဲတစ်ခုချင်းစီအတွက် ကံစမ်းခွင့်တောင်းခြင်းနှင့် မတူပါ။
4. နောက်တစ်ကြိမ်ဝင်ရန် **အကောင့်ဝင်ရန်** ကိုသုံးပါ။ အကောင့်အချက်အလက်မှ Profile ပုံ URL နှင့် ကိုယ်ရေးအချက်အလက်များ ပြင်နိုင်ပါသည်။

### မဲအစီအစဉ်ထဲ ဝင်ခြင်း

1. **မဲအစီအစဉ်များ** မှ မိမိဝင်လိုသော မဲကိုရွေးပါ။ အခြေအနေ၊ စာရင်းဖွင့်ချိန်၊ မဲဖောက်ချိန်နှင့် ဝင်ခွင့်ပုံစံကို ကြည့်ပါ။
2. စာရင်းဖွင့်ချိန်ရောက်ပြီး မဲမပိတ်သေးပါက **ကံစမ်းခွင့်ရယူရန်** ကိုနှိပ်ပါ။ မဲတစ်ခုစီအတွက် တစ်ကြိမ်စာရင်းတင်နိုင်ပြီး ကံစမ်းခွင့်အရေအတွက်ကို တောင်းဆိုနိုင်ပါသည်။
3. ဖုန်းနှင့် ဆုလက်ခံရန် ဆက်သွယ်ရန်အချက်အလက် ဖြည့်ပါ။ ပစ္စည်းဆုအတွက် လိပ်စာဖြည့်ပါ။ ငွေသားဆုရပါက အဆင်ပြေစေရန် KBZPay, WavePay, AYA Pay, CB Pay, ဘဏ်အကောင့် သို့မဟုတ် အခြားနည်းလမ်းကို ရွေး၍ အကောင့်ပိုင်ရှင်အမည်နှင့် ဖုန်း/အကောင့်နံပါတ်ကို ရွေးချယ်ဖြည့်နိုင်ပါသည်။
4. အခမဲ့မဲဆိုလျှင် တောင်းဆိုချက်ကို ပို့ပါ။ ရောင်းချမဲဆိုလျှင် မဲဈေးနှုန်းအလိုက် စုစုပေါင်းပမာဏကိုစစ်ပြီး ငွေပေးချေမှုအချက်အလက်ဖြည့်ပါ။ Promotion/ပွိုင့်မဲဆိုလျှင် ပွိုင့်လက်ကျန် သို့မဟုတ် Admin စစ်ဆေးနိုင်မည့် ကူပွန်အထောက်အထား လိုအပ်နိုင်ပါသည်။ App တွင် ငွေလွှဲ/ငွေလက်ခံမှု အလိုအလျောက်မလုပ်ပါ။
5. ပို့ပြီးလျှင် အခြေအနေသည် **စစ်ဆေးဆဲ** ဖြစ်ပါမည်။ Admin က မဲဝင်ခွင့်ကို အတည်ပြုပြီးမှ လှည့်ခွင့်ရပါမည်။ ငွေပေးချေမဲနှင့် ပွိုင့်မဲတွင် Admin က ငွေလွှဲ/ပွိုင့်ကို စစ်ဆေးပါမည်။
6. အတည်ပြုပြီးနောက် မဲဖောက်ချိန်ရောက်မှ မဲစာရင်းဘေးရှိ **ကိုယ်တိုင်လှည့်** ခလုတ်ကိုနှိပ်ပါ။ သတ်မှတ်/အတည်ပြုထားသော ကံစမ်းခွင့်တစ်ကြိမ်လျှင် Wheel တစ်ကြိမ်လှည့်နိုင်ပြီး အသုံးပြုပြီးသည့်အကြိမ်ကို ပြန်မရပါ။ မပေါက်နိုင်သည့်အလှည့်လည်း ရှိနိုင်ပါသည်။

### ဆုရပြီးနောက်

- **ဆုရရှိသူများ** တွင် မိမိဆုနှင့် လွှဲပေးမှုအခြေအနေကိုကြည့်ပါ။ ဆုကို Admin ထံမှ လက်ခံရရှိသောအခါ Admin က **ဆု လွှဲပေးပြီး** ဟုမှတ်တမ်းတင်ပါမည်။ အဲဒီအချိန်မှ ငွေ/ပစ္စည်းလက်ကျန်စာရင်းမှ ထုတ်ယူပါသည်။
- မိမိဆုကို အလှူပြန်ထည့်ရန် သို့မဟုတ် အခြားအတည်ပြုအသင်းဝင်ထံ လွှဲရန် ဆုကတ်ပေါ်ရှိ **ဆုကို လှူ/လွှဲရန် တောင်းဆို** ကိုနှိပ်ပါ။ လွှဲမည့်သူအတွက် account Email ထည့်ပြီး အတည်ပြုပါ။ Admin စစ်ဆေးအတည်ပြုပြီးမှ ဆောင်ရွက်မည်။

### အလှူစာရင်းတင်ခြင်း

**အလှူရှင်များ** မှ အလှူစာရင်းထည့်ပါ။ ငွေသား သို့မဟုတ် ပစ္စည်း၊ တန်ဖိုး/အရေအတွက်၊ ဆက်သွယ်ရန်နှင့် ပုံ URL ကိုဖြည့်ပြီးပို့ပါ။ Admin အတည်ပြုပြီးမှ စာရင်းရှင်းတမ်းထဲဝင်ပါမည်။

## ၂။ Admin အသုံးပြုပုံ

### အကောင့်နှင့် ဝင်ခွင့်ကို စီမံခြင်း

1. ပိုင်ရှင်က Firebase တွင် `admins/{Firebase Auth UID}` document ကို `role: "admin"` ဖြင့် ကြိုတင်သတ်မှတ်ထားရပါမည်။ Admin ခလုတ်များမပေါ်ပါက အကောင့် modal မှ UID နှင့် Admin document အခြေအနေကို စစ်ပါ။
2. **မဲနှိုက်သူများ** စာမျက်နှာရှိ **အကောင့်အတည်ပြုရန်** အပိုင်းမှာ အကောင့်အသစ် Register လုပ်သူများကို စစ်ပြီး **ခွင့်ပြုရန်** သို့မဟုတ် ပယ်ချပါ။ ဤအဆင့်သည် အကောင့်ကို မဲအားလုံးဝင်ခွင့်ပြုခြင်းဖြစ်သည်။
3. အောက်ဘက် **မဲနှိုက်သူများ** ဇယားမှာ ရွေးထားသော မဲတစ်ခုအတွက် တောင်းဆိုထားသည့် ကံစမ်းခွင့်ကို သီးခြားစစ်ပါ။ အခမဲ့မဲတွင် စာရင်းနှင့် အရေအတွက်ကိုစစ်ပြီး ခွင့်ပြုပါ။ ရောင်းချမဲတွင် ငွေလွှဲမှုကို၊ ပွိုင့်မဲတွင် ပွိုင့်/ကူပွန်ကို အပြင်ဘက်မှစစ်ပြီးမှ အတည်ပြုပါ။ အတည်ပြုချိန်တွင် လက်မှတ်ဝင်ငွေကို ledger ထဲသို့ထည့်ပြီး ပွိုင့်မဲဆိုလျှင် သတ်မှတ်ပွိုင့်ကို ဖြတ်ပါမည်။
4. မဲဝင်သူ၏ ဆက်သွယ်ရန်နှင့် ငွေသားဆုလက်ခံရန် အကောင့်အချက်အလက်ကို ထိုဇယားတွင်ကြည့်နိုင်ပါသည်။ ထိုအချက်အလက်များကို အများမြင်ရသည့် Winner စာမျက်နှာတွင် မပြသပါနှင့်။
5. အကောင့်စီမံခန့်ခွဲမှုတွင် အခြားအသင်းဝင်ကို ဆိုင်းငံ့၊ ပြန်ဖွင့်၊ မှတ်တမ်းတင်ပယ်ဖျက်နိုင်ပါသည်။ ဖျက်ခြင်းသည် ကိုယ်ရေးအချက်အလက်ကို ဖယ်ရှားပြီး မှတ်တမ်းကို audit အတွက်ထားသည့် soft delete ဖြစ်သည်။ Firebase Authentication user ကိုယ်တိုင်ဖျက်ခြင်း မဟုတ်ပါ။

### မဲအစီအစဉ်ဖန်တီးခြင်းနှင့် ပြင်ဆင်ခြင်း

1. **မဲအသစ်ဖန်တီးရန်** ကိုနှိပ်ပါ။ အမည်၊ အကြောင်းအရာ၊ ပုံ URL (မဖြစ်မနေမဟုတ်)၊ အခမဲ့/ရောင်းချ/ပွိုင့်ပုံစံ၊ အများဆုံးကံစမ်းခွင့်နှင့် အချိန်ဇယားကိုဖြည့်ပါ။
2. **စာရင်းဖွင့်မည့်ရက်/အချိန်** သည် ဝင်ခွင့်တောင်းဆိုမှုစတင်နိုင်မည့်အချိန်ဖြစ်သည်။ **မဲဖောက်မည့်ရက်/အချိန်** သည် ဝင်ခွင့်ပိတ်ပြီး Wheel စလှည့်နိုင်မည့်အချိန်ဖြစ်သည်။ ဒေသစံတော်ချိန်ကိုစစ်ပြီး ဖောက်ချိန်ကို ဖွင့်ချိန်နောက်တွင်ထားပါ။
3. အကြိမ်များစွာပြုလုပ်မည်ဆိုလျှင် 1–24 ကြိမ်နှင့် အကြိမ်ကြားရက်အရေအတွက်ကို သတ်မှတ်ပါ။ App က အကြိမ်တစ်ခုချင်းစီကို သီးခြား raffle အဖြစ်၊ သတ်မှတ်ထားသောရက်ခြားဖြင့်ဖန်တီးပါမည်။
4. ငွေဆုတစ်ခုချင်းစီ၊ ပစ္စည်းတန်ဖိုး/အရေအတွက်၊ စုစုပေါင်းဆုငွေကန်နှင့် နှစ်သိမ့်ဆုအရေအတွက်ကို ထည့်ပါ။ နှစ်သိမ့်ဆုကို ကျန်ငွေညီမျှခွဲခြင်း (ကျပ်ပြည့်) သို့မဟုတ် ဆုတစ်ဆုစီပုံသေငွေဖြင့် သတ်မှတ်နိုင်သည်။ ပုံသေဆုစုစုပေါင်းသည် ငွေကန်ထက် မကျော်ရပါ။ ရောင်းချမဲအတွက် ဈေးနှုန်းနှင့် ငွေလက်ခံမည့် ဘဏ်/Wallet ကိုဖြည့်ပါ။
5. **မဲအစီအစဉ်များ** စာမျက်နှာ သို့မဟုတ် အနှစ်ချုပ်စာမျက်နှာမှ **ပြင်ဆင်ရန်** ကိုနှိပ်ပါ။ စာရင်းဝင်သူ/လှည့်မှုရှိပြီးသားဆိုလျှင် အမည်၊ ဖော်ပြချက်၊ ပုံ၊ အချိန်ဇယားနှင့် မဲအများဆုံးကိုသာ ပြင်နိုင်သည်။ ဆု၊ ဈေးနှုန်းနှင့် ငွေကြေးစည်းကမ်းများကို မပြောင်းနိုင်ပါ။ မဲဝင်ခွင့်တောင်းဆို/အတည်ပြုပြီးသည့်အရေအတွက်ထက် မဲအများဆုံးကို လျှော့၍မရပါ။

### မဲဖောက်ခြင်းနှင့် ဆုစီမံခြင်း

- မဲဖောက်ချိန်ရောက်လျှင် **မဲအစီအစဉ်များ** မှ **ဒိုင်လှည့်** ကိုနှိပ်ပါ။ လက်ကျန်လှည့်ခွင့်ရှိသည့် အတည်ပြုမဲစာရင်းများမှ စနစ်က ရွေးချယ်ပါမည်။ ကံစမ်းသူကလည်း မိမိအတည်ပြုစာရင်းမှ ကိုယ်တိုင်လှည့်နိုင်ပါသည်။
- ကံစမ်းခွင့်တစ်ကြိမ်သုံးပြီးပါက ပြန်မရပါ။ ဆု slot တစ်ခုကို တစ်ကြိမ်သာ ပေးနိုင်ပါသည်။ ရလဒ်များကို **ဆုရရှိသူများ** တွင်ကြည့်ပါ။
- ဆုကို အမှန်တကယ်လွှဲပေးပြီးမှ **ဆု လွှဲပေးပြီး** ကိုနှိပ်ပါ။ လက်ရှိ UI တွင် **ဆု ပြန်သိမ်း** သည် `လွှဲပြောင်းပြီး` အခြေအနေရှိသောဆုတွင်သာ ပေါ်ပါသည်။ မလွှဲရသေးသော `လွှဲပေးရန်ကျန်` ဆုကို ပြန်သိမ်းရန် လုပ်ဆောင်ချက် မပါသေးသဖြင့် မလွှဲပေးဘဲ `လွှဲပြောင်းပြီး` ဟု မှားယွင်းမှတ်တမ်းမတင်ပါနှင့်။ ပြန်သိမ်းပြီးပါက အကြောင်းပြချက်နှင့် ledger အဝင်ကို မှတ်တမ်းတင်ပါမည်။
- ကံထူးရှင်၏ ဆုလှူ/လွှဲတောင်းဆိုမှုများသည် **ဆုရရှိသူများ** စာမျက်နှာထိပ်တွင်ပေါ်ပါမည်။ အချက်အလက်စစ်ပြီးမှ အတည်ပြု/ပယ်ချပါ။

### အလှူ၊ ငွေ/ပစ္စည်းစာရင်းနှင့် အစီရင်ခံစာ

- **အလှူရှင်များ** တွင်တင်ထားသော အလှူကို စစ်ဆေးပြီး အတည်ပြုပါ။ အတည်ပြုလျှင် ငွေ သို့မဟုတ် ပစ္စည်းအဝင်ကို ledger ထဲသို့ တစ်ကြိမ်စာရင်းသွင်းပါမည်။
- **ငွေ/ပစ္စည်းစာရင်း** မှ လက်ကျန်ညှိရန်ကိုသုံး၍ စာရင်းအဝင်/အထွက်၊ ပစ္စည်းအရေအတွက်၊ တစ်ခုတန်ဖိုးနှင့် မှတ်ချက်ကို ထည့်ပါ။ လက်တွေ့အဝင်/အထွက်နှင့် ကိုက်ညီအောင် ထည့်ပြီး မှတ်တမ်းမရှိဘဲ လက်ကျန်ကို မပြင်ပါနှင့်။
- **အစီရင်ခံစာ** မှ CSV ဒေါင်းလုဒ်လုပ်ပါ။ Excel သို့မဟုတ် Sheets ဖြင့်ဖွင့်ပြီး လိုအပ်သည့်ကာလ/အမျိုးအစားအလိုက် စစ်ဆေးနိုင်ပါသည်။ CSV တွင် လက်ရှိစာရင်းများပါဝင်ပြီး payout အကောင့်အချက်အလက်ကို မပါဝင်စေပါ။

## ၄။ လုံခြုံရေးနှင့် ဝန်ဆောင်မှုကန့်သတ်ချက်များ

- Register လုပ်ခြင်း၊ ကံစမ်းခွင့်တောင်းခြင်းနှင့် ငွေပေးချေခြင်းသည် သီးခြားလုပ်ငန်းစဉ်များဖြစ်သည်။ App သည် KBZPay/ဘဏ်မှ ငွေကို တိုက်ရိုက်လွှဲခြင်း သို့မဟုတ် အလိုအလျောက်အတည်ပြုခြင်း မလုပ်ပါ။
- Profile၊ အလှူနှင့် ဆုပုံများကို public HTTPS URL အဖြစ်သိမ်းထားသောကြောင့် link ရှိသူတိုင်း မြင်နိုင်ပါသည်။ လျှို့ဝှက်စာရွက်စာတမ်း သို့မဟုတ် ကိုယ်ရေးအချက်အလက်ပါတဲ့ပုံ မတင်ပါနှင့်။ ငွေလက်ခံမည့် account အချက်အလက်ကိုတော့ private မဲဝင်စာရင်းတွင်သာ သိမ်းပါသည်။
- လက်ရှိ Spark ဗားရှင်းတွင် ကျပန်းရလဒ်ကို browser က ရွေးပြီး Firestore Rules က လှည့်ခွင့်နှင့် ဆု slot ထပ်မရမှုကို ထိန်းချုပ်သည်။ Browser ကျပန်းရွေးချယ်မှုကို Server ဘက်က လွတ်လပ်စွာအတည်ပြုခြင်း မပါသဖြင့် တန်ဖိုးမြင့် သို့မဟုတ် တရားဝင်ထီအဖြစ်အသုံးပြုရန် မသင့်ပါ။
